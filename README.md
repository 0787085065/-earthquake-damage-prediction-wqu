# Earthquake Damage Prediction - WQU Project 4

Predicting earthquake damage levels using machine learning to help prioritize resources and save lives.

## 📊 Project Overview
Part of WorldQuant University (WQU) Data Science Lab. The goal is to predict the damage grade of buildings after an earthquake using structural and geographical features.

## 🗂️ Dataset
- Training data with building features: age, height, materials, floors, location
- Target: damage_grade (1 = low damage, 2 = medium, 3 = high)
- Challenge: categorical features, class imbalance

## 🔧 What I Did
- Exploratory Data Analysis (EDA) - distributions, correlations
- Feature Engineering - encoding categorical variables, handling missing values
- Model Building - Random Forest, XGBoost, Logistic Regression
- Evaluation - F1-score, confusion matrix
- Handling imbalance with stratified sampling

## 🛠️ Tech Stack
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn, XGBoost
- Jupyter Notebook

## 📈 Results
- Best model: Random Forest
- Key features: building age, foundation type, floor type
- Focusing on improving F1-score
